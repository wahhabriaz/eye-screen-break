# Architecture

```
main.py                     source entry point (adds src/ to sys.path)
src/eye_break/
  app.py                    composition root, CLI args, logging, single instance, lifecycle
  core/
    clock.py                Clock (real), ScaledClock (dev speed-up), FakeClock (tests)
    scheduler.py            pure-Python state machine (no Qt) — the heart of the app
    break_manager.py        Qt coordinator: 1 Hz tick, OS probes, overlay, stats, notifications
    reminder_manager.py     optional water/stand/stretch/posture/walk reminders
  services/
    settings_service.py     validated settings dataclass, atomic JSON, corruption recovery
    statistics_service.py   aggregation, streaks, CSV export
    quote_service.py        quotation/instruction rotation without repeats
    notification_service.py tray notifications + winsound
  database/                 SQLite connection (WAL), migrations (PRAGMA user_version), repository
  platform/windows/         ctypes: idle time, lock state, presentation state, sounds; HKCU Run key
  ui/
    overlay.py              full-screen break overlay (one window per monitor)
    main_window.py          sidebar + stacked pages (created on demand, released when closed)
    system_tray.py          tray icon and menu
    context.py              settings live-apply + debounced save shared by pages
    components/             design-system widgets (cards, toggle, segmented, ring, bar chart…)
    pages/                  overview, schedule, appearance, statistics, quotes, settings, about
    themes/                 design tokens, light/dark/system resolution, generated QSS
    icons.py                original SVG line icons and the painted app logo
  assets/                   quotes.json, app.ico/png, sounds (all generated by scripts/make_assets.py)
```

## Scheduling state machine

`Scheduler` (in `core/scheduler.py`) owns all timing decisions. It is driven by `tick(idle_seconds,
locked, presenting)` once per second and reports events (`state_changed`, `pre_break`,
`break_started`, `break_ended`, `session_reset`) through a callback.

States: `WORKING`, `PRE_BREAK`, `SNOOZED` (the three *active* states), `ON_BREAK`, `IDLE`,
`SUSPENDED` (locked), `PAUSED`, `MEETING`.

```
            interval reached              countdown ends / skip / emergency
 WORKING ───────────────────▶ ON_BREAK ─────────────────────────────────▶ WORKING
   │  ▲  notice window            │ snooze                                   ▲
   ▼  │                           ▼                                          │
 PRE_BREAK                     SNOOZED ── snooze time worked ──▶ ON_BREAK    │
 idle ≥ threshold ─▶ IDLE ── input returns (reset if long) ────────────────┘
 locked ─▶ SUSPENDED ── unlocked ─────────────────────────────────────────┘
 pause()/meeting ─▶ PAUSED/MEETING ── expiry / resume() / presentation ends ─▶ WORKING
```

Reliability rules:

- **Elapsed time, not counters.** Work time accumulates from monotonic-clock deltas between ticks,
  so late or irregular ticks cannot drift the schedule.
- **Sleep and hibernate.** A gap between ticks larger than 20 s is treated as system sleep: it is never
  counted as work, an open break is recorded as *interrupted*, and a long gap restarts the session.
  Only one counter exists, so breaks can never pile up after waking.
- **Clock changes.** Durations use monotonic time only. Wall time is used only for timestamps and for
  "pause until tomorrow".
- **No overlap.** `start_break` refuses while a break is active; the overlay controller replaces,
  never stacks, windows; previews are refused during a real break.
- **Idle accuracy.** When idle is detected, the idle-threshold window is credited back, so the
  minutes with no input are not counted as work or active time.
- **Live configuration.** Shortening the interval leaves at least 60 s before the next break.

## Overlay

`OverlayController` creates one frameless, `WindowStaysOnTopHint | Tool`, translucent `DimWindow`
per `QScreen`, sized to the screen's geometry (Qt handles per-monitor DPI). Each window paints
`QColor(0, 0, 0, alpha)` in `paintEvent`, so the dim strength is per-pixel alpha while text and
buttons are drawn fully opaque. Window opacity is animated only for the fade-in and fade-out. At ≥50% alpha,
Windows routes all clicks on the layered window to it, so underlying apps cannot be clicked.
`screenAdded`/`screenRemoved` rebuild the windows. The secure desktop (Ctrl+Alt+Del, UAC, lock
screen) is always above normal windows, so the overlay can never cover it.

## Data

- `%APPDATA%\EyeBreak\settings.json`: every field is validated on load, and invalid values fall back to
  defaults. Writes go to a temp file and `os.replace`. An unreadable file is renamed to
  `settings.corrupt-<timestamp>.json` and defaults are used.
- `%APPDATA%\EyeBreak\history.db`: tables `breaks`, `activity` (active seconds per day) and `kv`
  (quote rotation history). Migrations are tracked by `PRAGMA user_version`. A corrupt database
  is moved aside and recreated.
- `%APPDATA%\EyeBreak\logs\eye-break.log`: rotating, 3 × 512 KB.

Active time is buffered in memory and flushed every 60 s and at exit.

## Performance choices

- One 1 Hz `QTimer` drives everything; each tick makes three cheap Win32 calls. There are no threads and no
  high-frequency polling, and the dashboard repaints only while visible.
- The dashboard is created when opened and destroyed when closed to the tray, so the background
  process holds only the tray, the scheduler and the database connection.
- `PySide6-Essentials` only; charts and icons are painted with `QPainter`/`QtSvg`, and sounds use the
  stdlib `winsound`.
